Running Feedr

Requirements: .NET 10 SDK and a running SQL Server instance.
SQL Server Express and SQL Server LocalDB are also supported.

1. Check ConnectionStrings:DefaultConnection in Feedr/appsettings.json.
   The default uses SQL Server on localhost with Windows authentication.
   For SQL Server Express, change the JSON server value to .\\SQLEXPRESS.
   For LocalDB, change the JSON server value to (localdb)\\MSSQLLocalDB.
   Keep the rest of the connection string, including Database=Feedr_Day2.

2. Open Feedr.sln in Visual Studio and run Feedr, or run this from the
   extracted project folder:

   dotnet run --project Feedr/Feedr.csproj

3. Open the localhost URL printed by the application.

On startup, Feedr automatically creates the database and tables if missing
and fills an empty database with demo data for all ten tables. No manual SQL
import is needed. The SQL login must be allowed to create the database.
Existing populated databases and edits are preserved on later launches.
